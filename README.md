# Global Electronics Retailer — Sales & Customer Analytics

## Project summary
An end-to-end retail analytics portfolio project using Python to transform multi-table sales, product, customer, store, and exchange-rate data into business-focused insights.

## Business problems addressed
- Monitor revenue, profit, and margin over time.
- Identify top-performing categories and products.
- Flag high-revenue products with comparatively low margins.
- Measure customer revenue concentration and repeat purchasing.
- Segment customers using Recency, Frequency, and Monetary (RFM) metrics.
- Compare channel and store performance.
- Review delivery duration and data-quality risks.

## Methods
Data profiling and quality checks; text and currency normalization; date and numeric conversion; primary/composite/foreign-key validation; validated joins; feature engineering; KPI analysis; monthly trends; Pareto/customer concentration analysis; RFM segmentation; visual analytics; CSV exports.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.

## Key outputs
The notebook calculates total revenue, cost, profit, margin, order and customer counts, category/product performance, customer concentration, repeat-customer rate, RFM segments, channel/store performance, delivery metrics, and business recommendations. Exact findings are generated from the dataset when the notebook is run.

## Business value
The workflow supports commercial and operational decision-making by highlighting revenue drivers, margin-review opportunities, customer segments for engagement, and delivery performance areas for investigation. Findings are descriptive and should be validated before being treated as causal explanations.

## Reproducibility
Place the five source CSV files in the location configured in the notebook, then run all cells in order. The notebook exports a data-quality report and analytical CSVs to an `output` directory.
